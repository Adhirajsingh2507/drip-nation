# Design System

Before creating many UI components, establish a coherent visual system.

Define when appropriate:

## Typography
- display
- heading
- body
- label
- metadata

## Spacing
Use a consistent spacing rhythm.

## Color
Define semantic tokens rather than arbitrary colors.

## Components
Create reusable patterns for:

- navigation
- buttons
- links
- cards
- forms
- sections
- overlays
- product UI

## Layout

Define:

- container
- grid
- gutters
- section spacing
- responsive breakpoints

Avoid arbitrary values unless visually justified.
