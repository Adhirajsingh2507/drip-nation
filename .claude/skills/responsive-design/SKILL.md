# Responsive Design

Every page must be designed as a responsive system, not a desktop page shrunk down.

Evaluate:

- desktop
- laptop
- tablet
- mobile

Check:

- navigation
- typography
- spacing
- grids
- image crops
- content order
- CTA placement
- touch targets
- overflow
- horizontal scrolling
- forms
- modals
- menus

Do not simply stack everything vertically.

Make deliberate responsive decisions based on hierarchy and usability.

Test at:

1440x900
1280x800
768x1024
390x844
