# Visual QA

Visual QA is mandatory for significant UI work.

Use Playwright to inspect the actual rendered application.

## Minimum viewport matrix

1440x900
1280x800
768x1024
390x844

## Inspect

- visual hierarchy
- typography
- spacing
- alignment
- grids
- image cropping
- responsive behavior
- interactions
- hover states
- focus states
- animations
- overflow
- accessibility

## Refinement loop

Implement
→ render
→ inspect
→ identify highest-impact problems
→ fix
→ render again
→ inspect again

Never rely solely on source code inspection.
